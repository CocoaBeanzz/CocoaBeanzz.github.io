Borrowed science

Some of the best audio tools weren't made for audio.

When a problem in a master turned out to be a problem another field had already solved, Kouncil took the answer.

Resonances, found like spectral lines
Spectroscopy's baseline subtraction finds the narrow peaks. Keeping only what is there the whole song through tells a ringing frequency from the notes you play.
Ranges, set like a blood test's
Every profile is a reference interval, laboratory medicine's "normal range", measured from real records with robust statistics so one odd master can't skew it.
Codec frames, checked like JPEG blocks
The grid you see in an over-compressed photo has an audio twin at the codec's frame edges, and Kouncil looks for it the way image-quality metrics do.
Pumping, measured like a lecture hall
The speech-intelligibility test for rooms measures how much loudness movement survives. Kouncil asks the same of your limiter.
Codec delay, timed like sonar
Each decoded version is lined up with your master to the sample by the cross-correlation sonar uses to time an echo.
Timelines, drawn like an oscilloscope
Each pixel keeps the loudest and quietest moment it covers, so a single spike in a ten-minute track still shows at any zoom.

Under the hood

Measured properly.

Standards-checked loudness
ITU-R BS.1770 with the standard's own filters, tested against EBU Tech 3341 and cross-checked with ffmpeg's ebur128. Oversampled true peak.
Real codecs, not models
Every codec figure comes from an actual encode and decode, aligned to the original to the sample.
Thresholds from data
What gets flagged was set from measured commercial masters, not rules of thumb: 2,499 of them, across 100 genres.
Glitch-free playback
The audio engine runs in a process of its own, so a heavy analysis never stutters what you hear.
Batch it
A command line analyzes folders of tracks and builds profiles without opening a window.
Yours, offline
No account, no upload, no network connections. Your audio never leaves your computer.

Tech specs

What it reads, and how.

Audio files

Formats
WAV, AIFF, FLAC, ALAC, AAC, MP3, Ogg Vorbis, Opus. Lossless masters give the full picture
Channels
Stereo and mono. Surround files are mixed down to stereo
Sample rate
Any, measured at the file's own rate
Bit depth
Any, including 24-bit and 32-bit float, at full resolution

Measurement

Loudness
ITU-R BS.1770-4 / EBU R128: integrated, short-term, momentary, loudness range. Tested against EBU Tech 3341
True peak
4× oversampled, per channel
Codecs
AAC 128 and 256, Vorbis 160, Opus 128, MP3 320, SBC 192, and two chains: Vorbis into SBC, AAC into AAC. Real encodes, at the sample rate each service sends
Reference ranges
100 genre profiles measured from released records, or your own built from references

Output

Reports
PNG and JPG images, PDF, plain text
Kouncil's own
Snapshots (a track's whole analysis, reopened without the audio), profiles and skins, all shareable
