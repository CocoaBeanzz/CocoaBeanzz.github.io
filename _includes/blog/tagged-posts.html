{%- comment -%} Row of up to four posts about one project, newest first, from any department. A post counts when its `project` is the given name or the name is one of its tags. The post that simply embeds the project (its title is the project's name) is left out, since on the project's own page it would only link to a copy of the page being read. Usage: {% include blog/tagged-posts.html name="InfeStation" %} {%- endcomment -%} {%- assign tagged_count = 0 -%}
