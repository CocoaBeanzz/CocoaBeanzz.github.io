--- layout: default --- {%- comment -%} A music release: title, the embed as the centerpiece, where to listen, and lyrics. Everything but the lyrics comes from the file's front matter: layout: release name: "Fallen" released: 2024-05-21 image: /docs/assets/images/albums/Fallen.png # artwork, also used on tiles youtube: JQ5jCnLX_b0 # video id, the centerpiece soundcloud: tracks/1532809405 # instead of youtube: a SoundCloud player (see elements/soundcloud.html) youtube_playlist: OLAK5uy_... # optional, plays the id within this playlist links: # places to listen, in order - { label: "Spotify", url: "https://..." } tags: [Releases] # add Highlight to feature it on the landing The body of the file is the lyrics, typed as they should read: one line of the song per line, a blank line between verses. For a release with several tracks, start each track with "## Track name". With no body, the lyrics section is left off the page. A release whose body is a description instead of lyrics says so with `body: notes`. The text is then shown without the "Lyrics" heading. A release with neither `youtube` nor `soundcloud` shows its artwork in the embed's place. {%- endcomment -%}
